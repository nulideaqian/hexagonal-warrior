# Phase 1 · 打地基（8 周：2026-10-05 ~ 2026-11-29）

> 目标：跑通 AI 应用工程最小闭环 —— LLM API → Prompt 工程 → RAG
> 参数：平日 30min×5 + 周末 2h（≈4.5h/周）｜ 起步技术栈：Python（uv 管理环境）
> 规矩：平日 30 分钟到点即停，宁断勿滥；每周日复盘必查验收

## W1（10/05-10/11）环境 + 首次 API 调用

- 10/04 起跑日：uv 装 Python → 注册 API（DeepSeek/DashScope/智谱自选）→ 跑通 `chat.py` → 记坑
- 平日：读所选平台官方 quickstart，每天一个小实验（temperature / system prompt / 多轮 messages）
- 周末：多轮对话 demo + 结构化输出初探
- **验收**：`chat.py` 与 AI 完成一次真实对话

## W2（10/12-10/18）Prompt 工程

- 平日：每天一个 prompt 实验（角色设定 / few-shot / 格式约束 / 失败案例分析）

- **验收**：结构化输出小工具可用

## W3-4（10/19-11/01）项目① 电商文案/FAQ 助手
