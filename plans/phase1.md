## W2（10/12-10/18）Prompt 工程 —— 商品文案生成工具 —— 细化任务项

> 场景：输入商品参数（品类/规格/价格带），输出标题 + 卖点文案
> 目标：掌握 Prompt 设计核心模式，产出结构化输出工具

### T1 Prompt 基础设计（起跑）
- [ ] T1.1 写第一版 system prompt："电商文案专家"角色 + 输出要求
- [ ] T1.2 用户消息模板：商品参数组织成清晰结构（品类/规格/关键词/价格带）
- [ ] T1.3 跑通第一版：一个真实商品 → AI 返回能用的文案

### T2 核心实验（每天一个）
- [ ] T2.1 基线对比：同一商品用 3 种 system prompt，记录输出差异
- [ ] T2.2 few-shot：给 2 个好文案示例，看输出质量是否提升
- [ ] T2.3 格式约束：prompt 里明确要求 JSON，验收返回可解析

### T3 结构化输出（周末核心）
- [ ] T3.1 `response_format={"type":"json_object"}` 强制 JSON
- [ ] T3.2 `json.loads()` 解析返回，提取 title / selling_points 字段
- [ ] T3.3 批量模式：5 个商品循环生成（验收：一次跑完，输出结构一致）
