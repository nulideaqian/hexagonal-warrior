> **目标**：全方位转型 + 锻炼，保证生存技能可迭代更新（3-5 年生存导向）
> **教练**：六边形教练 ｜ **开训**：2026-10-04

## 仓库使用规则

| 目录 | 用途 | 谁来维护 |
|---|---|---|
| `projects/` | 每周作业代码（如 `w1-first-call/`） | **阿乾**（自己写自己 push，教练只验收） |
| `journal/` | 每周复盘 `W1.md` `W2.md` ... | **阿乾写**，教练批注 |
| `plans/` | 阶段计划详表 | 教练 |
| `debts.md` | 技术债账本 | 阿乾记，教练周复盘时审 |
| `README.md` | 总控 + 进度表 | 教练每周日更新 |
